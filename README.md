# Bright Bridge Scholars (BBS)

A Place of Opportunity.
Building Skills. Creating Value. Connecting Futures.

Official community website for Bright Bridge Scholars. A single-page static site (HTML, CSS, JavaScript) hosted on GitHub Pages.

## Files
- index.html: the full website
- logo.jpg: the official BBS logo

## How it works
Students complete the registration form. The details are emailed to the BBS team through EmailJS. The success screen then shows links to join BBS on WhatsApp, LinkedIn and Telegram.

## Updating links and settings
Open index.html and edit the CONFIG block near the bottom:
- whatsapp: WhatsApp community invite link
- linkedin: LinkedIn link
- telegram: Telegram invite link
- contactEmail: public BBS email shown in the footer
- emailjs: service, template and public key

## Publishing on GitHub Pages
1. Upload index.html and logo.jpg to the repository root.
2. Go to Settings, then Pages.
3. Under Branch, choose main and / (root), then Save.
4. Wait 1-2 minutes for the site link to appear.

## Testing checklist
- Site opens correctly on a phone, with no sideways scrolling
- Logo and all sections load
- Join buttons open the correct links
- A test registration reaches the BBS inbox
- Success screen shows all three platform links
